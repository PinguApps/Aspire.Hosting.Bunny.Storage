# Samples and demos

This repository includes two Bunny Storage sample entry points:

- `samples/AppHostSnippets` contains compile-checked AppHost snippets for documentation.
- `samples/BunnyStorageManual` contains a manual Blazor sample for local Azurite testing and deployed Bunny Storage testing.

The manual sample keeps application code on `IObjectStorage`; it does not call Azure Blob SDKs or Bunny APIs directly.
